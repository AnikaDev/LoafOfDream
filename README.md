| № | Название | Предусловие | Шаги | Ожидаемый результат | Статус |
|---|----------|-------------|------|---------------------|--------|
| ТС-01 | Успешная авторизация | Сервер запущен, пользователь зарегистрирован | 1. Экран входа.<br>2. Ввести данные.<br>3. Нажать «Войти» | Переход на список продукции, токен сохранён | Пройден |
| ТС-02 | Авторизация с неверным паролем | Сервер запущен | 1. Экран входа.<br>2. Ввести неверный пароль.<br>3. Нажать «Войти» | Сообщение об ошибке, перехода нет | Пройден |
| ТС-03 | Регистрация нового пользователя | Сервер запущен | 1. Перейти на регистрацию.<br>2. Заполнить поля.<br>3. Выбрать роль.<br>4. Нажать «Зарегистрироваться» | Успешная регистрация, возврат на вход | Пройден |
| ТС-04 | Поиск с историей | Авторизован, есть продукты | 1. Нажать поисковую строку.<br>2. Убедиться в отображении истории.<br>3. Ввести запрос.<br>4. Нажать поиск | История отображается; запрос добавляется в историю | Пройден |
| ТС-05 | Создание продукта (владелец) | Авторизован как owner | 1. Нажать FAB «+».<br>2. Заполнить поля.<br>3. Нажать «Создать» | Продукт появляется в списке | Пройден |
| ТС-06 | Запрет создания (продавец) | Авторизован как seller | Открыть экран списка продукции | FAB «+» не отображается; API возвращает 403 | Пройден |
| ТС-07 | Добавление выработки | Авторизован как owner | 1. Перейти в Производство.<br>2. Добавить 10 шт продукта.<br>3. Вернуться в список | Количество продукта увеличилось на 10 | Пройден |
| ТС-08 | Оформление продажи | Произведено 5 шт за текущую дату | 1. Перейти в Продажи.<br>2. Добавить 3 шт.<br>3. Нажать «Добавить» | Продажа оформлена, остаток = 2 шт | Пройден |
| ТС-09 | Продажа сверх остатка | Произведено 2 шт за дату | 1. Перейти в Продажи.<br>2. Ввести количество 5.<br>3. Нажать «Добавить» | Сервер возвращает ошибку о недостатке товара | Пройден |
| ТС-10 | Просроченные остатки | lastProducedAt более 24 ч назад | Перейти на экран Остатки | Продукт в секции «Просроченные» с красным маркером | Пройден |
| ТС-11 | Смена глобальной даты | Пользователь авторизован | 1. Открыть Календарь.<br>2. Долго нажать прошлую дату.<br>3. Подтвердить.<br>4. Перейти в Производство | Производство показывает данные за выбранную дату | Пройден |
| ТС-12 | Переключение тёмной темы | Пользователь на главном экране | Нажать переключатель темы | Тема переключается и сохраняется после перезапуска | Пройден |
